# Dos X — Arcade Manager

نظام إدارة بلايستيشن وكافيه (POS) بواجهة عربية RTL وثيم داكن.

## التشغيل

```bash
flutter pub get
flutter run -d windows
```

أو للويب: `flutter run -d chrome`

## الشاشات

- **الأجهزة:** شبكة الشاشات، مؤقت حي، اختيار فردي/زوجي، حساب الساعة
- **طلبات الكافيه:** إضافة أصناف للجلسة النشطة
- **الفاتورة:** وقت + كافيه − خصم، ثم تأكيد الدفع
- **الفواتير / تقفيل اليوم:** جدول اليوم وملخص الوردية
- **التقارير:** إيراد الوقت/الكافيه، المصروفات، صافي الربح
- **المخزون والإعدادات:** الأصناف، الأجهزة، الموظفين، والصلاحيات

قفل الشاشة من أيقونة القفل. كود الدخول الافتراضي: `12345`
